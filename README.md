MCG Intelligence

Macro–Liquidity–Leverage Bitcoin Overlay Engine

MCG Intelligence is a systematic macro overlay engine designed to dynamically adjust Bitcoin allocation based on structural regime, liquidity stress, derivatives leverage pressure, and institutional capital flows.

⸻

Architecture Overview

Phase 1 — Core Risk Engine
Phase 2 — Liquidity & Leverage Intelligence
Overlay v2 — Exposure Scaling Model
Daily Pipeline — Signal Engine
Dashboard — Institutional UI

Core Outputs
	•	Macro Risk Gauge (MRG)
	•	Core Risk Score (CRS)
	•	Liquidity Regime Score (LRS)
	•	Leverage Pressure Index (LPI)
	•	Institutional Bias
	•	Tactical Bias
	•	BTC Allocation Target
